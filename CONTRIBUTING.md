# Contributing to Awesome SaaS Valuation

Thanks for helping. This list is different from most awesome lists: **every entry is ranked by data**, so the rules are strict.

## What we accept

* **Corrections.** A number looks wrong, a link is broken, a category is mislabeled. Open an issue with what you saw.
* **New valuation cuts** that can be backed by a public, checkable number (asking multiples, revenue bands, churn, margins). Include the source and the sample size.
* **Better guides.** If you wrote an in-depth, data-backed guide to one valuation method, suggest it as a link under that section.

## What we do not accept

* Multiples with no sample size. Every number needs an n, and cells under 30 are not shown.
* Closed-deal claims we cannot check. This list uses asking multiples and says so.
* Affiliate links, course sales pages or "get rich" content.
* Manual edits to the ranked sections of `README.md`. Those sections are generated.

## How the README is built

The ranked sections are generated from a monthly data snapshot. The data is refreshed monthly by [BigIdeasDB](https://bigideasdb.com/?utm_source=github&utm_medium=awesome-saas-valuation&utm_campaign=contributing).

## Style

* One line per entry: name, link, then the numbers.
* Counts are rounded down with a `+` (for example `430+ listings`).
* No em dashes. Keep descriptions short and factual.
